## Why the two results differ

- The schemas differ by design: a V1 fact is one sentence with roles; a V2 fact is a headline over a tree of verbatim components with byte spans, laid out as coded tables. Counterparts are found on the shared bytes, not on wording.
- A section routed to more families in V2 (the routing widening by code and the V2 schema's subtypes) yields facts V1 never asked for; a section routed to fewer yields facts V1 had and V2 does not.
- A V2 fact held by validation (an unresolved component span, an invented role, an invalid tree) is not shown; a V1 fact over the same bytes then has no visible counterpart. The held fact and its code are listed under the section.
- The V2 tables place only facts carrying a readout; a V2 fact without one is listed under its section as evidence without a readout, with its V1 counterparts.
