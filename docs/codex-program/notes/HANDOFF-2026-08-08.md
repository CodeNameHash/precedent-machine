## The merge approach — decided 2026-08-08

**Merge the record now. Hold the code.**

The docs are pure additions with no runtime surface: `PLAN.md`, `COMPLETED.md`,
`DECISIONS.md`, and everything under `docs/codex-program/notes/`. Landing them
on `main` is what stops the next session re-deriving today's findings. There is
no risk in it.

The code is held on three concrete blockers, all closable in about an hour:

1. **The MAE materiality split is still in the code and we have already decided
   it is wrong.** Ben ruled to revert it (Step 2X-D, `DECISIONS.md` entry 14).
   Merging now ships a taxonomy decision that makes two deals with identical
   legal effect stop matching in precedent search. Red Hat currently carries 11
   claims on the code being retired.
2. **Seven commits are tagged UNREVIEWED or wip.** They were committed to
   satisfy the stop hook while agents were mid-flight, not because the diffs
   were reviewed. `CLAUDE.md` forbids committing unreviewed delegate output; the
   tags are honest labelling, not compliance. The absence-copy port across 11
   config files is the one to look hardest at — its author's account has been
   read, its diff has not.
3. **Nothing user-facing has been live-verified.** The absence change alters
   what a reviewer sees across 11 families. A green build is not a working page.

Order to unblock: revert the MAE split → diff-review the seven WIP commits
against their criteria → live-verify one page per changed surface → re-run the
three gates → merge the code.

## The finding everything hangs on

Resolution rate by family, `resolved / review_queue`, all 2026-08-08 runs:
**52.8% overall (1,415 of 2,679), with 3,031 open-world candidates.**

Flat, one-fact-per-sentence families resolve at 100% — misc-boilerplate,
tax-matters, material-contracts, merger-structure. Families drafted as a chapeau
over lettered limbs resolve at 13–26% — financing covenants 13%, termination
17%, representations 22%, interim operating 26%.

The resolver is not failing. It is handed fragments with no parent to inherit
from and correctly refuses to guess. That is the whole argument for Step 2X.

## Traps this session created or hit. Do not repeat these.

**A run receipt is not the model's output.** The receipt records what the
*shaper produced*. Concluding that a producer emits nothing because the receipt
shows nothing is wrong, and it was the load-bearing error in the first draft of
Step 2X. Red Hat's REPRESENTATIONS responses contain 69 limbs; the receipt shows
none, because the shaper discards them. **Read `raw_response_text`.**

**`review_queue` is the attempted set, not a reject pile.** It carries every
attempted claim with `has_resolution` and `auto_pass` flags. Adding it to
`resolved` double-counts and produced a reported 34.6% corpus rate that should
have been 52.8%. The rate is `resolved / review_queue`.

**`pgrep -fc` matches the checking shell's own argv.** It reported four builds
running when there was one, and earlier reported work alive when everything was
dead. Count via `/proc` with the checking shell excluded.

**Never pipe test output into `head` or `tail`.** A pipeline returns the last
command's exit code and will report success on a failing suite. Redirect to a
file, `echo $?`, then grep the file.

**Byte offsets are UTF-8; `indexOf` and `slice` are UTF-16.** `subclauses.js`
works in string indices and must stay that way — it has 8 passing tests and four
live V1 consumers. Convert at the boundary.

**Background agents die silently.** Two did today and neither notified. Verify
by artefact — did the file grow, did the branch move — not by notification.
