# Codex — the corrected run brief

**Supersedes `codex-overnight-2026-08-10.md`, which was red on arrival.** An
adversarial review ran the suite rather than reading it and found the brief
walked the agent into a deadlock, plus an arithmetic error in its own success
criterion. Both are fixed here.

Read `docs/codex-program/notes/stage-2y/route-to-good-extraction-2026-08-10.md`
for the historical reason the plan changed. The short
version: the diagnosed register tops out around 51–77% placed, not 85%; the one
cohort ever measured delivered 22% of plan; and ~280 of 2Y-A's 575 fragments
land back in open-world unless 2Y-H exists first.

**A second adversarial pass then changed three more things**, all reflected
below. The headline metric is now **rendered rows a lawyer can use**, not placed
percent — because resolved-but-invisible claims already exist in the corpus
today. **2Y-H's spec has changed**: it is not a "topic present" claim family but
a joined projection of limb-plus-attached-qualifier, because the qualifiers are
not missing, they are one `subject_occurrence_id` join away — 86 of 86 Metsera
limbs share that key with 107 qualifier claims. And **ladder rung 3 model
deferral is pulled forward**, resolve-only, because it is bounded, cheap, and the
evidence for it is 91 of 91 derivations returning null with zero genuine
conflicts.
