## Method

- Rebuild each deal once via `rebuildAdmittedSourcePrimitives`.
- Slice `section-location-scan.json` `resolved` spans with `utf8Slice` (byte offsets).
- Dedupe `(deal, section_reference, start, end)`.
- Run current `findStructuralMarkers` and baseline copies from `git show`.
- Convert `tokenStart` (UTF-16 string index) → UTF-8 bytes at the boundary via `utf8ByteLength(text.slice(0, i))`, then add section start for document-absolute `marker_start_byte`.
- **Start move definition:** set difference on abs_byte. Surviving starts are identical by construction (`tokenStart` is the physical `(`). Dropped starts (no longer structural) are reported separately — not as moves. Label-greedy rematching of dropped↔new is rejected (it pairs distinct physical tokens).
- Mis-nest signature: same-style parent-child link on the path (governing-structure SAME_STYLE_CHAIN instrument).
