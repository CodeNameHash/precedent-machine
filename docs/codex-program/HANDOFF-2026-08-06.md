They answer different questions and both are needed.

### How to run it

`scripts/canonical-v2-live-extraction-run.mjs`, one process per family, in
parallel. Six to ten at once worked without throttling. `--dry-run` resolves
sections and reports projected call count without calling a model, so map
families to sections for free before spending anything.

Modiv's family-to-section mapping is in the commit for `4788860b` and in each
evidence directory's run manifest. **TopBuild's mapping does not exist yet and
must not be assumed from Modiv's**: TopBuild has 63 sections to Modiv's 99 and
its articles do not align, Modiv's termination sitting at 7.1 while TopBuild's
boilerplate runs to 7.16.

Expect roughly 70 model calls and $25 for Modiv. The first sweep measured 58
calls and $20.30 for 25 families; citation-following is now on by default but
is scoped to termination-fee bare-citation triggers and adds nothing elsewhere.
TopBuild is an estimate, not a measurement: perhaps 50 to 60 calls.

Capitalisation was the outlier at 18.8 minutes and timed out on its second
call. Use `--call-timeout-ms` above the 600,000 default for that family.

## What to be careful about

**The documents have drifted from the system repeatedly, in both directions.**
`docs/codex-program/notes/doc-reality-audit.md` records 28 findings, and a
separate agent has been reconciling the tracking documents against it. Trust
the commit messages and the code over any document that has not been checked.

**One error class has produced three separate confident false findings**: using
a JavaScript string index, which counts UTF-16 code units, against a UTF-8 byte
offset. This pipeline slices text by bytes everywhere. A conversion helper
exists. Any probe using `indexOf` or `slice` against a stored offset will
produce a plausible wrong answer.

**A zero from a family is not necessarily a failure.** Guaranty on Modiv
returns nothing because the agreement genuinely lacks those provisions.
Treating that as a defect means inventing provisions the deal does not have.

**Never pipe `npm test` into `tail` or `head`.** The pipeline returns the last
command's exit code and will report a passing suite when it failed. Redirect to
a file, echo `$?`, then grep.
