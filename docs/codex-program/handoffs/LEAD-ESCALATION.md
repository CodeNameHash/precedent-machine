# Lead escalation channel

This branch exists only to carry a draft pull request whose comments wake
the lead session. Nothing is ever pushed here after creation.

Who may comment: the external agent (coord/m7-ext), the Deal Storylines
agent (coord/deal-terms) and the coordination clerk session. When: only
for a BLOCKED question that no recorded assumption lets you proceed on,
or a delivery that needs the lead's integration or ruling. Comment body:
the channel, the Q id, one sentence. Routine questions go to the clerk
through the normal inbox and are answered within about ten minutes.
