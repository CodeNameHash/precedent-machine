## Q-0018: modal-and-limb census of the fixed 50

For each of the 50 items' nodes, and for each item's governing chapeau
from your Q-0012 closures, list with byte spans (UTF-8 half-open over the
canonical text, text SHA-256 of each span):

- every operative modal token: `shall`, `shall not`, `will`, `will not`,
  `may`, `may not`, `must`, `is entitled to`, `is required to`;
- every enumerated child limb: M2 children of the node by kind
  (`AUTHORED_INLINE_LIMB`, `LIMB`, `QUALIFICATION`, `CHAPEAU`, or whatever
  kinds the index carries; report the kinds you find), with their
  markers such as `(i)`, `(a)`, `(A)`;
- every proviso or exception marker: `provided that`, `provided,
  however`, `except`, `except that`, `unless`, `other than`,
  `notwithstanding`, `subject to`, `to the extent`, `so long as`.

Output: one JSON table (item ordinal, node id, entries with kind, text,
start, end, sha) and a markdown summary with counts per item and per
kind. Acceptance: every span sha-verified against canonical bytes; the
script re-runs byte-identical; no span invented (a marker inside a
quoted defined term is still reported, flagged `inside_defined_term`).

## Q-0019: temporal-and-amount census of the fixed 50

For each item's node span: every duration (`thirty (30) days`, `six
months`, `5 Business Days`), date, money amount, percentage and share
count present, with spans. Then, for each such string, call the existing
parser modules in `lib/canonical-v2/native-producer/*-parse.js` directly
on that substring: find the exported function names by grep, cite module
and line, record the parser name and whether it returned a typed value
(record it) or abstained. Where no parser fits the kind, record
`NO_PARSER`.

Output: one JSON table and a markdown summary with counts (parsed /
abstained / no parser) per kind and per item. Acceptance: spans
sha-verified; byte-identical re-run; every parser cite is a real export
(grep result in the report).
