# Archive

Created 2026-08-05.

**Nothing in this directory is current.** Everything here is superseded
material kept for provenance: what a decision was at the time, and why. Do
not treat any file here as a live specification, plan or status report. If a
statement here conflicts with code, tests, or anything under `docs/` outside
this directory, the other source wins.

Nothing here is read by application code, tests, scripts or CI. That was the
condition for moving it: every candidate was checked against `tests/`,
`scripts/`, `lib/`, `pages/`, `components/`, `supabase/`, `sql/`,
`package.json` and `.github/` before the move, and anything with a live read
or write stayed where it was.

| Path | What it is |

| `handoffs/` | Agent-to-agent handoffs, slice specs, live-run write-ups and proposals, 2026-07-16 to 2026-08-04 |

Subdirectory structure is preserved from `docs/`, so a path that used to be
`docs/handoffs/X.md` is now `docs/archive/handoffs/X.md`.

## What deliberately did not move

These sit next to the archived material and look similar, but they are live
and stayed in place:

- `docs/audit/` and `docs/audits/` — generated by `scripts/audit/*.js`, which
  write to those exact paths. `scripts/audit/schema-parity.js` runs in CI.
- `docs/learn/loss-audit-handoffs.jsonl` — appended at runtime by
  `pages/api/admin/schema-loss/decide.js`.

## Stale pointers left on purpose

A few references to the pre-archive paths were not rewritten, because the
files holding them are byte-pinned or are recorded evidence:

- `supabase/canonical-v2-serving.sql` (SHA-256 pinned function body) and its
  frozen copy in `sql/optionA/`.
- Recorded live-run fixtures under `tests/fixtures/canonical-v2/`.
- Historical per-phase allowlists in `.github/phase-allowlists/`.

Read `docs/handoffs/...` in those files as `docs/archive/handoffs/...`.
