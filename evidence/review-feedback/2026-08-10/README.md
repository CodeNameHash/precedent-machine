# Ben's review of 65 rendered rows — 2026-08-10

The defect taxonomy in `docs/core/PLAN.md` Phase C is derived from this file and
from nothing else. It is committed because an adversarial review pointed out that
a programme insisting on artefact-backed claims had built a whole phase on
feedback that lived only in a chat window.

`ben-row-feedback.json` is the verbatim export from the rendered-rows artefact
(`PM_STAGE_2Y_N_ROW_FEEDBACK/V1`): 65 of 310 cards, each with a verdict of
RIGHT / WRONG / THIN / UNSURE and free text.

**Read the caveat before using it.** These verdicts were given against the FIRST
version of the artefact, which had a presentation bug: when key-matching failed
it showed the first three rows of the section's catalogue rather than the claim's
own row. 297 of 310 cards displayed rows with no established link to their
excerpt. So every note reading "cross contamination", "dupe of N", or "why is
this appearing so many times" is describing that bug, not the pipeline.

What survives the caveat, because it is visible in the cells regardless of which
row was shown: missing parties, the dropped chapeau, raw enums on the page, lost
operative words, absence copy dumped inline, and unanchored durations.
